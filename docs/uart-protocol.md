# UART与模型启动协议

115200 baud、8N1。命令按请求/回应串行执行。电脑使用核心板CH340串口，FPGA RX=F12、TX=D12。不要和下载控制器的另一组串口混用。

| 命令 | 内容 |
| --- | --- |
| P | 读取固件回应 |
| W | 命令字＋LE24字节地址＋LE16个16字节块＋payload＋payload CRC32 LE32 |
| T | 命令字＋一个读等待值2～4；修改后撤销模型有效标志 |
| V | FPGA完整回读模型区并核验冻结CRC |
| A | 开启自动相机推理 |
| B | 停止自动相机推理，预览继续 |
| S | 读取相机/显示/模型/推理运行状态 |
| I | 已准备输入的推理，返回8层CRC和CTC |
| R | 命令字＋LE24对齐地址，读取16字节 |

本识别版不使用停车D命令或时间C命令。模型位于0x100000，输入位于0x140000。每个W载荷必须16字节对齐，1～1024块；最小启动程序每次4096字节，逐块校验后再核验全模型。

回应固定128字节：

| 字节 | 内容 |
| --- | --- |
| 0..3 | ASCII TCH1 |
| 4、5 | 命令、flags |
| 6、7 | 字符数(0..32)、协议版本1 |
| 8..11 | 模型CRC |
| 12..15 | 最近上传的CRC |
| 16..19、20..23 | 运行周期、预取等待周期 |
| 24..55 | 字符索引；T/A/B的字节24为参数/模式 |
| 56..87 | 8层特征CRC，S/R使用相应状态/突发字段 |
| 88..119 | 各层完成周期 |
| 120..123 | build ID 0x20261028 |
| 124..127 | 前124字节的CRC32 |

CRC为IEEE reflected 0xEDB88320，初值全1、末尾取反；多字节整数little-endian。flags位0为SDRAM初始化，1为模型校验通过，2为核心错误，3为协议错误，4为层扫描重叠，5为已完成；bit7:6为时钟码1=25MHz、0=50MHz。有效自动I结果低6位为0x23。

S回应字节56..71为4个LE32：状态flags、已发布帧数、显示欠载数、推理次数。状态flags位0相机配置完成、1相机故障、2内存就绪、3模型就绪、4自动模式、5忙、6桥接故障、7服务故障；8..11故障码、12..13重试数。

最小启动顺序为B→等待相机/内存就绪→W上传→T/V全量校验→A→读取真实I结果→S确认。优先尝试已验证的读等待2，失败再尝试3、4；没有全量CRC匹配就停止。关闭串口连接不会关闭FPGA自动模式。
