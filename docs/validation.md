# 验证范围与边界

## 原版实板记录

交付bit于2026-10-31已有实板验证：3种冻结输入各10次，共30次FPGA推理、240个层CRC和CTC一致；实际相机同次ROI的8层CRC与独立整数参考一致；显示欠载增量0。平均板上周期换算532.877ms，不含主机上传图像耗时。

之后恢复原版时，50个构建输入的字节哈希与原bit构建记录全部相同。曾因重配置后没有加载权重而出现预览正常、推理次数0；加载权重及A启动后，实拍8层CRC再次一致，后续观察到297次推理，显示欠载0。由此提供独立的最小启动程序，明确区分下载bit与加载SDRAM模型。

`verification/cnn_simulation.json`为475648元素逐层仿真证据，`video_simulation.json`为13项视频/控制检查；`original_pnr.json`保留资源和时序结果。日志摘要是历史证据，不代替在另一块板上的验收。

## 精度不能与数值一致性混淆

原整数模型固定主测试4000张整牌准确率95.65%，非皖515张86.41%；明暗压力测试3072个派生变体82.88%。派生变体不是独立3072个号码，离线集也不代表所有摄像头实拍场景。T/1、0/8等混淆和亮屏拍摄问题仍有残留。

8层CRC一致证明相同输入下FPGA与整数参考计算一致，不证明镜头前号码识别正确。当前场景没有真实号码标签时，不把候选预测计作准确率。完整车牌在绿框内、合适大小、无裁断和饱和是本固定ROI方案的前提。
